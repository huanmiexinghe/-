04

关键取舍与实现说明

层级：先给「下一步」让路

主 CTA 从 320×68 放大到 560×118，并与每日挑战并排占据首屏最重的一行；关卡与无尽退为等宽模式卡；联机、自定义、成就收成 64 高的小卡。设置从独立入口改为右上 64×64 齿轮，重置折叠进设置弹层，仍然二次确认。

间距：三条水平线规整节奏

全部左右留白统一 56；行间距固定 16 / 22；卡片高度只用 118 / 88 / 64 / 44 四档。信息密度靠高度分层，而不是靠字号堆叠，避免小屏拥挤。

点击区：按实机换算后仍 ≥ 44

横屏 844×390 时画布等比缩放到 693×390（缩放 0.722）。最小卡 64 逻辑像素 → 46.2 CSS px；齿轮 64 → 46.2；模式卡 88 → 63.5；主 CTA 118 → 85.3。所有入口都大于 44 px 的拇指命中下限。

触屏与键盘互不打架

点击沿用上一轮的「抬起且未拖动（阈值 12px）才触发」，拖动不会误开场景；onPointerDown 只负责按下态。键盘用 ↑↓←→ 在同一视觉行内移动、跨行按最近中心点选取，回车确认；设置弹层内 Esc 逐层关闭。
