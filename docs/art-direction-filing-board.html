反直觉发现

很多人以为"AI 味"来自满屏渐变。但全项目 createLinearGradient 只有一处（天空）， createRadialGradient 零处。柔和感的真正来源不是渐变，而是 统一圆角 + 统一硬投影 + 每个物体都挂一圈同色光晕。所以"去掉渐变"这个常见建议在这里是无效的—— 要动的是圆角、光晕和描边权重。

02 / DIAGNOSIS

为什么它看起来「像 AI 生成的」

八条可验证的诊断。每条都给出代码里的实际取值或实测数据，不给"感觉"。

D1两套互斥的世界观同时存在于仓库里

src/data/levels.ts 里 36 个关卡每个都写了 bg，取值是 #0a0a0f、#141026、#2a1018 这类暗色——是上一版"暗色霓虹"美术的遗产。 而 GameScene.ts:1760 先用它清屏，紧接着 GameScene.ts:1839 的 drawToonSky() 又把整块 960×540 覆盖成糖果天空。 36 个关卡的背景配置 100% 是死代码。

这说明：项目经历过一次美术转向，但没有做完——旧配色没有被删除，新配色也没有被定义成唯一来源。观众看到的"不协调"不是形状问题，是没有一个做决定的人。

红系 5 个值里 #ff4d6d 和 #ff2d5e 的色相只差 1°（349° vs 348°）， 人眼基本无法区分，但代码里一个是"极性"、一个是"致命"。颜色在这里不携带信息，只携带热闹。 没有主色—辅色—强调色的从属关系，只有一堆"彼此独立的漂亮颜色"。

这就是最典型的 AI 味：生成式配色倾向于在同一个明度/饱和度带上，用等间距的色相铺满， 每个颜色单独看都"没错"，放在一起没有主次。

一个跑酷游戏，最需要被看见的三种东西——蓝障碍、红障碍、收集物——是画面上对比度最低的三种。 这不是审美问题，是玩法问题。

D4所有元素同一种描边，等于没有主次

toonShape() 默认 lineWidth = 3；角色 3、尖刺 3、石柱 3、平台 3、相位墙 3、终点 3、HUD 胶囊 3、按钮 3。 全画面 76 处 3px。当 40px 的角色和 600px 的面板用同一条粗细的线，视觉上就没有"主体 / 结构 / 纹样"的层级， 所有东西都在同一个平面上喊叫。

修法：线宽必须变成 3–4 级的信息，而不是一个默认值。

D5圆角一刀切，所有东西一样软

实际用到 6 / 7 / 8 / 9 / 10 / 12 / 14 / 16 八个近值，且每个都按元素短边的固定比例取。 结果：尖刺底座是圆的、石柱是圆的、平台是圆的、角色是圆的、终点是圆的、连坑口都是圆的。 当"危险"和"可站立"拥有相同的柔软度，玩家只能靠颜色分辨危险——而颜色刚好又不可辨（见 D3）。

D6光晕是公式化的：每个物体都被无理由地强调

激光 fillRect(x−5, w+10) @0.28、终点外发光 lineWidth 5 @0.35–0.75、磁芯雨外圈 r+6 @0.22、 极性区填充 @0.28、摆锤充能环 0.30–0.65、石柱警示灯 0.20–0.45。 六种完全不同的东西，同一套"同色半透明外扩"配方。当每个元素都发光，光就不代表任何东西了。 编辑器/联机 HUD 里还继续沿用同一套硬投影 + 圆角卡片，于是整个画面是同一种质感的无限复制。

D7数学上的完美重复——这是最硬的一条

太阳 12 条光芒等角分布（每 30° 一条）；4 朵云写死在数组里；草簇精确 90px 等距； 远山近山是两条纯正弦函数（菜单背景）；晶片浮动 sin(time*3 + x)；就连障碍间距也基本是整数。 人手画的云不会四朵等间距，手画的太阳光不会 12 条一样长。

这是"像 AI"最直接的物理证据：画面里没有任何一处随机扰动、粗细变化、端点收笔、错位。 所谓"手绘感"，技术上就是可控的不规则。

D8细节密度均质 + 可爱三件套

每个障碍都被塞进同样多的装饰：柱身左高光 + 右暗部 + 26px 横纹 + 法兰螺栓 + 黄黑帽 + 呼吸灯 + 圆角。 平台也要有云朵托底 + 顶面高光 + 木纹 + 两颗螺栓。而背景（山、草）几乎零细节。 没有"主角细节多、中景少、远景只剩剪影"的景深分层。

再加上：圆角 + 两只眼睛 + 白色椭圆高光——角色有眼睛，摆锤球也有眼睛。这是"可爱安全牌"的三件套， 是生成式卡通最常见的选择，也是最能被一眼认出来的。

03 / MOTIF

视觉母题：一块铁屑沙盘

一句话母题

世界是一块铺满细铁屑的磁性板面；
磁极走过的地方，铁屑会立起来、排成力线；
全画面只有带电的东西有颜色 —— 铁是灰的，电是亮的。

为什么是"铁屑"，而不是"赛博 / 扁平 / 几何"

磁极唯一真实的视觉形态就是铁屑实验：撒一把铁粉在磁铁周围，粉末会沿磁场方向立起来，形成一道道梳齿。 这比霓虹光效、能量线、粒子爆发都更有出处——它来自物理，不来自特效库。所以美术不用"发明"一个风格， 只需要忠于这个设定本身。

这个母题能直接推出四条可执行规则

设定中的事实推出来的美术规则
铁屑是灰色的，只有被磁化的地方才有方向环境永不带饱和色。板面/结构/远景一律铁灰，占画面 85% 面积
磁极会"拉"铁屑，铁屑跟着磁极动粒子与尾迹统一为铁屑，不留圆形光点。摆锤的磁力场、切换冲击波都变成"铁屑被吸起"的短线
真实磁铁两端刻着 N / S极性必须带刻印。红极 = "+"、蓝极 = "−"，这条形状编码贯穿所有元素，同时解决色弱可辨
铁屑是脏的、不齐的、有毛边的装饰必须是可手绘的颗粒与力线。禁止云、太阳、彩虹、星星、光晕等"生成式默认装饰"
沙盘是桌面上的一个物理装置一切结构是"加工件"。平台是切出来的板，石柱是车出来的轴，尖刺是磨出来的刃——有硬边、有倒角、有加工痕

落地到元素名词上，整套美术只需要记 6 个词： 板面（board）· 铁屑（filings）· 力线（field line）· 带电体（charged）· 极性刻印（+/−）· 刃口（edge）。

手绘感的三个可控参数（"反 AI"的技术落点）

  • 端点收笔：所有刻线/力线用 lineCap='round'，但两端长度 ±2px 随机，且不做闭合路径。
  • 不规则节奏：草簇/铁屑间距不用固定 90，改为 52 + rand(0,64)，用关卡 seed 做确定性随机（保持回放一致）。
  • 颗粒错位：颗粒 1px 短线允许 ±0.5px 亚像素偏移，让边缘"脏"起来——这是区分"矢量化"和"画出来"的关键。

底线：危险物在任何氛围下都必须清晰

这是跑酷游戏唯一不能妥协的事。当前代码里至少有三处会破坏这条底线，新方案要逐条堵住。

现有风险点

位置问题后果
GameScene.ts:1805 particles.render() 在障碍与角色之后绘制 连击爆发 40 颗、加速流光、死亡碎片全部盖在尖刺/激光之上——最需要看清的一帧恰好被粒子糊住

新方案的五条硬规则

#规则可测判据
R1分层固定：板面 → 力线/颗粒 → 结构 → 障碍 → 角色 → 危险提示 → 氛围 → HUD。粒子属于"氛围"，永远在障碍之后画，且受 R2 限制z 序写进一处常量，不散落在各 render 里
R2氛围不得覆盖危险物：任何全屏叠加（连击脉冲、风暴、白闪）透明度上限 0.18，且必须在屏幕边缘做 vignette 渐隐，中心 60% 区域不叠叠加层中心 alpha ≤ 0.18；危险区像素 alpha ≤ 0.06
R3轮廓优先于填充：所有带电体必须有 2px 铁屑亮边；亮边不参与任何透明度动画（充能时闪的是琥珀外框，不是亮边）去色 + 缩到 160×90 后，危险物剪影仍完整可数
R4对比度下限：危险物填充对其紧邻背景 ≥ 3:1；不足时补亮边（蓝对结构块 2.88 → 亮边 3.45）可写成 selfcheck 断言，见 §9
R5预警必须预示同一种危险：琥珀虚线 = 将出现致命判定，琥珀脉冲 = 充能；两者都不允许用于装饰或奖励全项目搜索"琥珀 + 非危险语义"应为 0 处
为什么深色背景反而更安全

不是"深色好看"，而是数学：亮背景把可用对比度上限压死了。糖果天空的亮度是 L 0.739–0.917， 任何饱和色的 L 都在 0.18–0.35，两者相除得到的对比度必然只有 1.2–3.0——除非把彩色也调亮到发白，那就失去了极性。 把背景压到 L 0.02 之后，同样的红/蓝立刻拿到 3.5–5.6。这是用背景换前景的对比度预算。

08 / CHECKLIST

避免「AI 味」的操作清单

每条都能直接执行、能验收，不是"要有设计感"这种废话。

  1. 调色板锁死在 11 个值删除 UI.color 里的 mint/grape/lemon/sky/success；删除 COLORS 里重复的 REVERSE_ZONE / SPECIAL_ITEM / GRAVITY；删除 36 关的 bg 字段。任何新颜色必须先进 theme.ts 并说明角色。
  2. 一条不可违反的色彩规则：饱和色只属于带电体环境（天空/山/草/云/地板/面板）饱和度上限 8%。这条一条就能干掉 70% 的"AI 感"。
  3. 描边只允许 1/2/3/4 四个值把 76 处 lineWidth:3 按"角色=3 / 带电体=2 / 结构=2暗边 / 刻线=1"重新分配；对不上的说明该元素没有定位。
  4. 圆角只允许 0/4/8/12删除 6/7/9/10/14/16。所有"软硬"必须能对应到"可通行/会伤人"。
  5. 删除所有椭圆高光块Player、摆锤球、石柱、平台的白色椭圆高光全部删掉。高光只保留"1px 亮边"和"顶面受光唇"两种。
  6. 删除 90% 的光晕只保留蓄能危险物外的一圈琥珀虚线。传送门外环、激光外扩、晶片光晕、星核光晕、石柱呼吸灯全部删除。
  7. 删除全部"生成式默认装饰"太阳、云、彩虹、星星、四角闪、光斑——一个不留。装饰只允许力线与铁屑颗粒。
  8. 引入确定性不规则草簇/铁屑间距用 seed 驱动的 52 + rand(0,64)；线段端点 ±2px；颗粒 ±0.5px 亚像素偏移。必须用关卡 seed，保证回放和每日挑战一致。
  9. 限制细节密度（景深分层）角色 ≤6 个细节件、危险物 ≤3 个、结构 ≤2 个、远景 ≤1 个（只剩颗粒）。超了就删，不要加。
  10. 给每个物体一个"加工方式"落地的说"铸造/车削/切割"，画的时候就会自然出现倒角、磨痕、厚度差，而不是 r=16 的圆角矩形。
  11. 禁止再给物体加眼睛只有主角有"面部"（且是护目条不是眼睛）。摆锤球的 N/S 保留，眼睛删除。
  12. 网格对齐所有刻线端点、颗粒、力线锚点对齐 6px 网格。手绘感来自粗细和断点，不来自错位到奇怪坐标。
  13. 一次只引入一个新形状新增障碍先从现有 4 种形状语言（刃、板、轴、环）里挑，不发明第 5 种。

最小改动的真实差别
